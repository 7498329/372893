# 兰州牛肉面 · 一碗面的十二种活法

一支 8 屏的线性叙事 H5。淡水墨国风、米黄宣纸底、浅青墨色，全程以用户提供的原画素材为唯一图像来源。

## 发布（线上版）

成品目录是 `dist/`，只含 `index.html` + `assets/`（约 1.9 MB），无外部依赖、无构建步骤：

```bash
python publish.py     # 把 index.html / README.md / assets 同步进 dist
```

改完源文件后重跑一次 `publish.py`，再发布 `dist/` 即可。原图、调试脚本、截图都留在上级目录，不会上传。

## 运行

直接双击 `index.html`，或用任意静态服务器打开（推荐，避免个别浏览器对本地 webp 的限制）：

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/index.html
```

无外部依赖，无需构建。

## 设备适配

- **竖屏页（P1/P8）**：750×1334 等比缩放到视口内（`contain`），超高屏幕上下留纸色边，绝不裁切海报；桌面端居中显示为"画框"。
- **横屏页（P2–P7）· 竖持手机**：不再把 1334×750 缩到 390 宽（那样文字只剩原尺寸三成，根本看不清），而是把整个横版舞台 **旋转 90°、按视口铺满**渲染——用户把手机横过来就得到一张正立、与横屏手机同尺寸的满屏横版。顶部同时浮出「请把手机横过来」提示条（4.2s 自动隐去，`pointer-events:none`，不挡操作）。
- **横屏页 · 手机已横持**：`rot=0`，按 `min(vw/1334, vh/750)` 等比放大到贴边（`contain`），与旋转态的视觉尺寸几乎一致，转动手机不会出现跳变。
- **平板 / 桌面竖窗**：屏幕够大，保持等比缩小（`contain`），不做强制旋转——平板自己转个方向就是原生横屏。
- **坐标换算**：旋转后 `getBoundingClientRect()` 返回的是包围盒，已全部弃用；统一走 `toClient / toStageXY / toStageVec` 三件套（`view.rotL` + `view.kl` 精确求逆），拖拽吸附、时间轴甩动、自检坐标在横竖屏与旋转态下都一致。
- **视口变化**（地址栏收放、横竖屏切换、桌面拖窗口）统一走 `refit()` 去抖重算，时间轴位移随之归一化，不会翻页错位。
- **桌面输入**：时间轴支持鼠标拖拽 + 滚轮/触控板横向翻屏；全站支持 ← → 方向键翻页与节点浏览。
- **首屏遮罩**：等封面解码完成再揭开，避免白闪与素材零散弹入；带两层兜底（整页 `load`、2.6s 定时），网络再差也不会卡在遮罩上。

## 交互细节

**翻牌（P2/P3）**
- 每张木牌点击触发绕 Y 轴翻转，正面→背面 180°，再次点击继续同向旋转到 360° 回到正面。
- 背面为竖排短文（取自 `面型` 文档，掐成两句、各十余字，保证不溢出木牌）。
- 翻转结束 0.9s 后有 0.2s 轻微回弹（`scale 1 → 1.035 → 1`）。
- 两页数据完全独立：`flipCount = {2:0, 3:0}`，各自计数、各自焦点，互不影响。

**拖拽（P4）**
- 指针事件实现，按住即拿起（放大 1.04、投影加深），松手判定。
- 落点用逻辑坐标计算（`left/top + 位移 + 半宽高`），不依赖 `getBoundingClientRect()`，避免 CSS 过渡期间测到中间值。
- **位置自锁**：每次按下时先把当前位置"焊"到 `left/top` 上并清掉残留 `transform`，反复拖拽不会累积漂移；`pointerup` 同时挂在元素与 `window` 上，指针捕获失效也能正常收尾。
- 落入碗口椭圆（rx 196 / ry 164，含 10px 容差）自动吸附到预设槽位，并伴一圈白色涟漪。
- 四类全部入碗 → 0.2s 后成品碗淡入（1.3s）+ 白色热气升腾（5 缕，3.8s 循环）+ 碗旁弹出「你的专属面做好了」。
- 拖到碗外自动滑回原位，不误吸附。
- 白萝卜与白瓷碗同色，落碗后额外补一层贴身暖影 + 接触影 + 碗内极淡暗角，保证浅色料始终看得见（不修改素材本身）。
- 复位用 class 而非 inline 样式，`placedSet` 一并清空——从 P8 点「再拉一碗」重玩时不会误判"已满碗"。

**时间轴（P5–P7）**
- 主线就是用户提供的「历史脉络面条」原图：把面条按列重映射到一条设计好的正弦曲线上（`build2.py`），既保留原画笔触与厚度，又能自由控制蜿蜒形状。
- 5 个节点刻意落在波峰/波谷，使弹窗上下都有整块留白，绝不压住面条。
- 点击节点：该节点所在面段（上一节点与下一节点中点之间）整段染成辣椒红——用 SVG `mask` + `feColorMatrix` 只显影这一段，**保留面条本身的高光与肌理**，不是盖一条色块。
- 弹窗位置在渲染后按实际高度动态计算，优先选空间更大的一侧，并避开左上角标题。
- 左右拖拽/甩动翻屏（3 屏），滚到第 3 屏才出现「收尾」按钮。

**全局**
- 页面切换 0.72s 缓淡入；按钮按下 `scale(.94~.95)` 回弹。
- 手机竖持进入横版页（P2–P7）时，横版舞台整体转 90° 铺满，并提示「请把手机横过来」；不再申请全屏 / 强锁方向（全屏会一直全屏，回到竖屏的 P8 会被挤成一条，退出入口还难找）。
- 支持 `prefers-reduced-motion`。
**封面「那碗面颠三下」（P1）**
- 同一张海报叠了两层：底层完整静止，上层用 `clip-path: inset(27.7% 0 0 0)` 只留"碗与面"那半幅，接缝落在副标题下方的纯纸面（取的是原图 524/1920 行，全行无内容，肉眼无缝）。
- 入场 0.8s 淡入放大照旧由底层完成；上层在 0.86s 后淡入（与底层像素完全重合，看不出切换），1.1s 起连颠三下：−18px → 落地 → −9px → 落地 → −4px → 停。
- 只有纯位移、没有缩放：海报里的黄底按钮与 HTML 的「开始制作」按钮必须严丝合缝，任何缩放都会让两者错开一两像素。按钮用同一组关键帧、同一时长与缓动同步跳。
- 动画结束自动摘掉（`animationend` → `.hopDone`），否则 `animation-fill-mode: both` 会一直压住按钮的 `:active` 回弹。重回封面时会清掉标记，动画可以再演一次。

## 调试入口

- `?dbg=1|2|3|4|5|8` —— 直接定格到某一屏（静态，关闭动画）。
- `?dbg=2f|3f` —— 定格为前三张已翻面。
- `?dbg=4r` —— 只把白萝卜放进碗里（检视浅色料的可辨识度）。
- `?dbg=4all` —— 四类食材全部入碗但不出成品。
- `?dbg=4done` —— 定格为面已做好。
- `?dbg=5a|5b|5c` —— 定格时间轴第 1/2/3 屏并选中节点。
- `?dbg=4done&anim=1` —— 带动画预览（可看热气）。
- `?t=1` —— 自动跑一遍交互自检，结果写入页面标题与 `body[data-test]`。
- `?hit=1` —— 点击穿透检查：用 `elementFromPoint` 逐个验证当前屏可见控件是否真的点得到，结果写入 `body[data-hit]`（`?dbg=2&hit=1` 可逐屏验）。
- `?click=1` —— 端到端点击：在「开始制作」按钮中心派发一次真实命中的点击，1.4s 后回报是否翻到第 2 页，结果写入 `body[data-click]`。
- `?geo=1` —— 几何探针：打印当前视口、`rot`（0/90）、`kl` 与横版舞台的包围盒、中心点，用来核对「旋转后是否精确居中且没溢出」。`body[data-fit]` 一直在线，随手 `F12` 就能看到。

自检覆盖：翻牌 180°/360°、两页互不干扰、碗内吸附、碗外不吸附、拖后不漂移、重复拖拽不漂移、成品与提示、节点染色、节点切换、整体复位、封面跳动挂载与同步、复位后二次游玩、坐标正逆变换、舞台包围盒、舞台不出屏、旋转判定，共 20 项。

竖持手机时 `?t=1` 与 `?hit=1` 都在 `390×844` 下复跑过（旋转态），P2–P5 的翻牌、拖拽、时间轴控件 `hit=OK`、`blocked=0`。

## 「页面打开后点不动」的成因与修复

两个竖屏舞台（`#stageP` 750×1334）与横屏舞台（`#stageL` 1334×750）都绝对定位在视口正中、`z-index` 相同。`#stageL` 在 DOM 里靠后，即使 `opacity:0` 也照常参与命中测试，于是在竖屏页（P1/P8）它像一块透明玻璃盖住了整屏，把「开始制作 / 再拉一碗」全挡住了。

- `.stage{pointer-events:none}`、`.stage.live{pointer-events:auto}`：只有当前启用的那块舞台接收点击。
- `#veil.gone{pointer-events:none}`，并给遮罩加 `animation:veilAuto 3.4s forwards` 兜底：脚本没跑起来也会自己消失，不会永远挡在门口。
- `revealCover()` 里给 `.on` 加了 `setTimeout(…,120)` 双保险：后台标签页或被隐藏的 iframe 中 `requestAnimationFrame` 会挂起，页面可能停在「透明但存在」的状态，同样点不动。
- 回归验证：`?hit=1` 在 1920×1080 / 1280×800 / 390×844 下 P1–P8 全部 `hit=OK`；`?click=1` 三档尺寸均 `click=hit page=2 OK`。
